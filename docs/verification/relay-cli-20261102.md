## 実装

- `relay/client.py`：標準ライブラリだけで既存のConsole HTTP APIへ接続するPython client。
- `relay/cli.py`／`relay/__main__.py`：status、control、stop、history list／seek／adopt。
- `pyproject.toml`：`relay` entry point。未インストールでも、repo内なら`python -m relay`を使える。
- サーバー／API／ブラウザのコードは変更しない。接続先の再起動を要求しない。
- 同じtoken、client ID、sequence、expected_epochによる既存の権限処理を使う。
- 巻き戻し・採用は受理と完了を区別し、自分の対象branch／step／採用client IDを確認する。
- POSTの再送はしない。競合、セッション交代、受理後のエラー、完了待ちtimeoutを終了コードとreceiptで区別。
- stopは先にPOSTし、状態表示は最大1秒だけ確認。受理後のGET失敗で停止の受理を取り消さない。

- snapshot取得不能でも先に停止を送る。停止後の別開始は競合として報告する。
